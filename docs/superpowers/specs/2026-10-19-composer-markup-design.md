# 饼干在线审片 · 写意见区与标记编辑器重排 · 设计稿

日期：2026-10-19
参考：二个零工作流程「在线审片」客稿页（写意见卡与「在当前帧画标记」工具条两张截图）
前置：`2026-10-15-biscuit-review-design.md`，以及 10-17 已完成的「照参考站改意见反馈形式」（提交 0ad822b）。

## 1. 目标与范围

把审片页右栏的「写意见」区域和「在当前帧画标记」的编辑器改成参考站的形式。

做：
- 写意见区按参考站重排（两个并排入口按钮、内嵌时间码与字数的输入框、并排「确认本版通过 / 提交意见」）。
- 标记编辑器从全屏弹层改为**播放器原位**编辑，工具条两行，功能与参考站对齐：画笔下拉（画笔/箭头/矩形/椭圆）、文字、移动画面、调整标记、缩放、虚线、四色 + 调色、清空、撤销/重做、完成/取消。
- 不画标记也能直接提交文字（现状已支持，保持；提交按钮在三者皆空时置灰）。

不做：
- 附件仍只支持图片（压缩后入 D1，每条最多 6 张）。视频/音频附件需要 KV 存储与分片上传，另立一期。
- 手势捏合缩放、多选标记、标记旋转/缩放单条。
- 后端接口、数据库、冒烟测试不变：提交给后端的仍是标记大图 + 缩略图 + 文字 + 图片附件。

## 2. 写意见区（composer）

只在「当前版本 + 意见填写中 + 饼干角色」显示，位于卡头「客稿 Vn 审片 · 当前版本 · 写意见与本轮反馈同屏 + 日间/黑夜」之下，是一个带边框的内卡。

布局自上而下：
1. **两个并排按钮**：「在当前帧画标记」「选择附件 / 图片」。
   - 没加载视频时「在当前帧画标记」置灰，title「先选择客稿视频」；标记编辑器打开期间显示「正在画标记…」并置灰。
   - 「选择附件」打开图片选择器（多选）。超过 6 张或非图片时 toast，与现状一致。
2. **预览区**：已画的标记预览（缩略图 + 「继续编辑 / 移除」+ 一句「标记画面取自 00:12.040，时间码已锁定到这一帧」）；已选的图片缩略图九宫格（每张可 ✕ 移除）。两者都空时不占位。
3. **输入框**：`textarea`，上限 1000 字，placeholder「输入对当前客稿的具体反馈…」。框内底部一行：
   - 左：时间码芯片，按钮。未锁定时随播放器实时显示 `时间码 00:00.000`（毫秒格式）；画了标记后锁定到抓帧时刻；点一下切成「整片 · 不带时间码」，再点切回。它取代原来的「整片」勾选框。
   - 右：字数 `0/1000`，随输入更新。
4. **并排按钮**：「确认本版通过」（描边）「提交意见」（主色）。文字、标记、附件三者皆空时「提交意见」禁用；提交中显示「正在提交…」并禁用。「确认本版通过」从状态卡挪到这里，行为不变（有未提交草稿时先提示；确认弹层）。
5. **说明**：「提交后仍可继续补充；全部写完后，请结束本轮反馈通知剪辑师。附件只支持图片（JPG、PNG、WebP），每条最多 6 张，会压缩到 1280px。」

状态卡（本轮状态）在「意见填写中」只保留「本轮反馈结束」；「已结束」「已通过」状态下的按钮不变（写意见区那时不显示）。

页头右侧小状态卡文案：饼干 + 填写中 + 0 条 → 「等待您的意见 / 可逐条提交，之后仍能继续补充本轮。」；有 n 条 → 「意见填写中 · 已写 n 条 / 写完请点「本轮反馈结束」。」其余分支不变。

草稿对象仍由 `review.js` 持有（`state.draft`：text / whole / lockedTimecode / annotation / attachments），composer 原地读写；切换版本、结束本轮、发布新版时对草稿的检查逻辑不变。

## 3. 标记编辑器（markup）

### 3.1 挂载

点「在当前帧画标记」：播放器暂停、抓当前帧（最长边 ≤ 1280）。播放器把**舞台**和**控制条位置**借给编辑器：视频与空态隐藏，舞台里放画布；控制条隐藏，同位置放工具条。右栏照常可见可滚动。完成或取消后归还，视频回到原来的帧。大屏模式下同样适用。

播放器只提供 `borrowStage({ stage, bar })` 返回 `release()`，不知道标记的存在；编辑器不碰 `video`。编辑器打开期间播放器的快捷键（空格、方向键）不响应。

### 3.2 工具条（两行，深色，在舞台下方）

第一行：
- **画笔˅**：按钮文字显示当前形状名（画笔 / 箭头 / 矩形 / 椭圆），点开下拉选形状；选中即成为当前工具。
- **文字**：点画面定位出现输入框，回车放置，Esc 取消输入。
- **移动画面**：拖动平移视图。
- **调整标记**：点一条标记选中（画虚线包围框），拖动整体移动；Delete / Backspace 删除选中；点空白取消选中。
- **−  100%  +**：缩放 50%–400%，每步 25%，围绕画面中心；显示当前百分比。

第二行：
- **虚线**：开关，对画笔/箭头/矩形/椭圆生效。
- **红 黄 蓝 白** 四个色块；**调色**：打开系统取色器，选的颜色成为第五个色块并选中。
- **清空**、**撤销**、**重做**（无可撤销 / 可重做时置灰）。
- **完成**、**取消**。Esc = 取消（文字输入框打开时 Esc 只关输入框）。

### 3.3 数据与绘制

- 标记：`{ tool: 'pen'|'arrow'|'rect'|'ellipse'|'text', color, dashed, points: [[x,y],…], text? }`，坐标为画布像素（与抓帧尺寸一致），便于再次编辑。
- 视图：`{ scale, tx, ty }`，只影响显示与指针换算；绘制时 `setTransform(scale,0,0,scale,tx,ty)` 画底图和标记。导出大图/缩略图时忽略视图，按画布原尺寸导出（与现状一致：1280 / 320，JPEG）。
- 画布 `object-fit: contain` 填满舞台；指针坐标先换算到画布内容框，再按视图逆变换到画布坐标。
- 历史：快照栈（`history` / `future`，各上限 50），新增、移动、删除、清空前都入栈。
- 纯几何（视图换算、内容框、包围盒、命中判定、平移）独立成 `js/markup-geo.js`，有 node 单元测试。

### 3.4 提交

「完成」→ `onDone({ full, thumb, strokes })`；`review.js` 把 `{ full, thumb, strokes, base, timecode }` 存到草稿并锁定时间码。「继续编辑」用草稿里的 `base` 和 `strokes` 重开。与现状一致。

## 4. 文件边界

| 文件 | 变化 |
|---|---|
| `js/composer.js` | 新建。写意见内卡：DOM、字数、时间码芯片、附件选择与缩略图、标记预览、提交/通过按钮状态。 |

| `css/review.css` | composer 样式、工具条样式；删除全屏 `.markup` 样式。 |
| `test/markup-geo.test.mjs` | 新建。`node --test` 跑几何函数。 |

## 5. 验证

- `node --test test/` 几何单测通过。
- 本地 `web`（8788）+ `api`（8787）：`npm run migrate:local` 补齐本地库；ffmpeg 生成 10 秒测试视频，通过分片上传接口托管到本地项目，审片页自动加载（不依赖文件选择器）。
- 内置浏览器走查：
  1. 不画标记直接写文字 → 提交，列表出现、时间码为当时播放位置；点芯片切整片 → 提交，列表显示「整片」。
  2. 画标记：四种形状、虚线、换色/调色、文字、缩放与移动画面、调整标记移动与删除、撤销/重做、清空；完成后预览与锁定时间码；继续编辑能还原；提交后列表缩略图可点开大图。
  3. 取消与 Esc 不留痕迹，播放器恢复。
  4. 选图片附件 → 缩略图 → 提交。
  5. 日间 / 黑夜、手机宽度（375px）下工具条可用。
- 远端冒烟 32/32（接口未变）。
